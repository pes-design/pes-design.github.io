# PES Portfolio — optimized GitHub Pages build

Эта папка полностью готова к публикации.

1. Загрузите **содержимое этой папки** в корень репозитория GitHub.
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch → main → /(root)** и сохраните.

Не загружайте ZIP как единственный файл: GitHub Pages должен видеть `index.html` и папку `assets`.

Сборка оптимизирована для быстрой первой загрузки: фотографии и прозрачная графика переведены в WebP, скрытые галереи и видео загружаются по мере необходимости. Исправлены отображение курсора и подгонка вертикальных фотографий в полноэкранном просмотре.
